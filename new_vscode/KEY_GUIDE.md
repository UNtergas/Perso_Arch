# Key guide: VS Code with the nvim keys

VS Code runs VSCodeVim (`vscodevim.vim`). The nvim keys are in two places, both generated by `build.py` from one table:
`settings.json` (the `vim.*KeyBindings` blocks, leader = Space) and `keybindings.json` (Ctrl / Alt chords VSCodeVim cannot see).
Not tried in a running VS Code yet (the setup session could not drive the GUI): see "First run" at the end.

## Harpoon (the extension `tobias-z.vscode-harpoon`)

Not installed yet: install it from the Marketplace, or these keys say "command not found".

| Keys | Does |
|---|---|
| `SPC h a` | Add this file to the list |
| `SPC h s 1` .. `SPC h s 9` | Put this file in slot N |
| `SPC h 1` .. `SPC h 9` | Jump to slot N |
| `SPC h h` / `SPC h d` | Edit the list (delete or move entries); there is no separate "remove this file" command |

The Marketplace build is 1.5.0 (2024). It has 9 slots. If a jump should go to an editor that is already open in another group, set
`"workbench.editor.revealIfOpen": true`.

## Lazygit

`SPC g g` opens a terminal in the editor area with the `lazygit` profile (`terminal.integrated.profiles.linux` in `settings.json`);
it closes when you quit lazygit. `SPC g f` uses the `lazygit-file` profile, which runs `lazygit -f ${file}`: VS Code has to
substitute `${file}` in profile arguments, which I could not confirm. If `SPC g f` shows the whole log, say so.

## Missing or different

| nvim | VS Code |
|---|---|
| Oil | The Explorer (rename, move and delete go through VS Code) |
| Telescope pickers | Quick Open, Find in Files, the Command Palette |
| `C-w r` resize mode, `C-w c` / `C-w C`, `C-w q` numbering | None (resize with `C-k h/j/k/l`, `C-w z`) |
| `C-k` resize in 10% steps | VS Code's own step |
| Undo tree (`SPC s u`) | Timeline: file history, not an undo tree |
| `SPC f R`, `SPC c d` / `D`, `]f` `[f`, `SPC o m` | Not mapped |
| The keys block, tab row, statusline colours, which-key popup | Not ported. A which-key popup would be the `VSpaceCode.whichkey` extension, a separate menu you maintain twice |
| `Esc Esc` in the terminal | The terminal handles its own keys |

## First run

1. In VS Code the settings reload by themselves. Open a file, press `SPC` then `SPC`: Quick Open should appear.
2. Try `s` (flash), `gd`, `SPC g g`, `C-\`, `M-j`, `C-w \`.
3. If a key does nothing, `SPC h k` (keyboard shortcuts) shows what is bound; send Claude the key.
